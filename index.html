SorayLabs builds CLI agents, background workers and event connectors that take repetitive coordination work off small technical teams. We are starting with one concrete tool: a Discord bot that turns player bug reports into clean GitHub issues.

What we are building

We start narrow: one tool, for one kind of team, that we can ship and show. The rest of the toolchain grows from it.

First: bug-report triage for game communities
Open-source prototype

Players report bugs in Discord in every possible way. Our worker reads those messages, asks Claude to pull out the steps, platform and severity, and files a structured issue in your GitHub repository for a human to review.

  • Runs as a Discord bot on a small Linux server
  • Written in TypeScript on top of the Claude API
  • A moderator approves each issue with one click before it is created
  • Made for indie studios and game creators with a Discord community
  • Open source (MIT): github.com/louisjcb/soray-bug-triage

Next: terminal-first agents
Planned

Later: event-driven orchestration
Planned

The triage worker generalizes into a small orchestration layer.

  • Ingest webhooks from GitHub, Discord and CI/CD runners
  • Route tasks to specialized sub-agents
  • Automatic error recovery and retry logic

How we use Claude

Claude does the reading. Deterministic code and a human make the decisions.

Model
Claude through the Anthropic API, Claude Haiku 5.5 by default and configurable per deployment
Output
Forced tool use returns a fixed schema, and the bot validates every field before anything reaches GitHub
Untrusted input
Player messages are treated as data, never as instructions
Human review
A moderator approves each issue with one click by default
Cost control
Short messages are skipped, non-bug messages get no reply, and calls are rate-limited

How the pieces fit

This is the architecture we are building toward. The first release covers one path: Discord message, worker, triage agent, GitHub issue. Failed steps are retried instead of dropped.

Built on a plain, durable stack

No exotic platform to adopt. Our tools run on Linux, talk to open APIs and keep your code on your machine.

Agent runtime
Node.js / TypeScript and Python, calling Anthropic’s API directly
Hosting
A small Linux VM per deployment, such as a DigitalOcean Droplet or an Azure Linux VM
Bot
discord.js, with GitHub issues created through Octokit
This site
Static HTTPS pages on GitHub Pages at soraylabs.me
