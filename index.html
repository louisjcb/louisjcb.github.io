What we build

Modern language models can reason about code. Developers still need tooling that is local-first, testable and predictable around them. That is the gap we work on.

Terminal-first autonomous agents

Lightweight CLI utilities that work where you already work: your local directories and your Git history.

  • Analyze a codebase and run multi-file refactoring passes
  • Run your test suite and react to the results
  • Format clean, readable Git commits
  • Built on the Claude API and the Claude Code execution model

Event-driven workflow orchestration

Background workers that listen to events and trigger precise, deterministic actions.

  • Ingest webhooks from GitHub, Discord, CI/CD runners and live game platforms
  • Route high-level tasks to specialized sub-agents
  • Automatic error recovery and retry logic

Live operations & community tooling

High-availability connectors for creators who run live communities.

  • Keep server health in sync with your community hub
  • Turn player and user reports into a real-time bug pipeline
  • Dispatch live updates to Discord and other channels

How the pieces fit

Events come in, a deterministic worker decides what to do, specialized agents do the work, and failed steps are retried instead of dropped.

Built on a plain, durable stack

No exotic platform to adopt. Our tools run on Linux, talk to open APIs and keep your code on your machine.

Agent runtime
Node.js / TypeScript and Python, calling Anthropic’s API directly
Workers
Linux micro-instances on DigitalOcean Droplets and Azure Linux VMs
Bots
Discord bot operations running as automated worker loops
This site
Static HTTPS pages on GitHub Pages at soraylabs.me
