# SorayLabs — Official Website

Source code and assets for the official [SorayLabs](https://soraylabs.me) landing page.

- **Production URL:** [https://soraylabs.me](https://soraylabs.me)
- **Deployment:** GitHub Pages with custom domain and enforced HTTPS
- **Stack:** Plain semantic HTML5, pure CSS, optimized vector SVGs, zero external runtime dependencies

## Repository Structure

- `index.html`: Main landing page and live-ops presentation
- `404.html`: Custom fallback routing
- `logo.svg`, `favicon.svg`, `og-image.png`: Brand identity and Open Graph metadata
- `sitemap.xml`, `robots.txt`: Search crawler indexing and SEO definitions
